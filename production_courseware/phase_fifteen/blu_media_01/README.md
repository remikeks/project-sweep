# BLU learning materials

Six SWEEP Academy courses, SWP-091 through SWP-096. Each has a learner-guide PDF, a three-page practice worksheet PDF, an editable PowerPoint and the matching slide PDF. Guides use 12-point body text. Videos are planned for a later phase.

Follow the cases, try the worksheets and then check the feedback. The cases and numerical examples are fictional. Refer real assessment, authority and funding decisions to qualified teams.

Verified course CBT passes are required for badges. Certification requires completion of all six courses, the mixed ParaLearn school exam, human marking and moderation of written work, and authorised signatures from the Head of Learning and Founder Prof. Mina Ogbanga. Published questions in the source repository are review examples. Graded delivery needs unpublished items.
