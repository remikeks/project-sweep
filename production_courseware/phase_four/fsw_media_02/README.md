# FSW PDF and slide review materials, batch two

Five draft courses, SWP-037 through SWP-041. Each has a six-page learner-guide PDF, three-page practice worksheet, sixteen-slide editable PPTX and matching sixteen-page slide PDF: twenty resources, eighty editable slides and 125 final PDF pages.

Version 0.1.0, English, draft for review. Academic, Nigerian practice/legal and accessibility/pilot approvals are pending. These files are designed learning resources, not recorded videos or a published badge-bearing release. The learner bundle contains no course CBT answer keys or private school-exam marking guidance.

The five source courses are in `../fsw_batch_02/review_package.json`. Guides and worksheets use a 12-point body font. Decks use the established SWEEP Academy cover illustration, navy/green/white styling and editable text on a 16:9 canvas. Full teaching and references remain in the guides and deck notes; slides provide teaching points and practice prompts.

Every final PDF page was rendered with Poppler and visually inspected, including all final slide pages exported from the actual PPTX through isolated LibreOffice. All eighty slides passed PPTX package, geometry, font and Artifact Tool import checks. Native Microsoft PowerPoint was not used. Automated checks also confirmed every source teaching paragraph, case, activity and feedback in the guide, all module titles, and all fifteen teaching points per course in both the editable decks and slide PDFs. No clipping or overlapping text was found in the final renders. This is production QA, not independent academic or accessibility approval.

`upload_manifest.json` records the twenty final file hashes, resource types and intended in-review state. `package_validation.json` binds the source package digest and file verification results. Private operational receipts and QA images are excluded from Git.
