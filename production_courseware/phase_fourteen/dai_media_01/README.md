# DAI learning materials

Seven SWEEP Academy courses, SWP-084 through SWP-090. Each course includes a learner-guide PDF, three-page worksheet PDF, editable PowerPoint and matching slide PDF. Guides use 12-point body text and identify the guidance or research behind the exercises. Video lessons are planned for a later phase.

Use the supplied fictional records and fixed sample outputs for the activities. Try the worksheet before reading the guide or slide feedback. Refer decisions about real cases, account access and client information to agency supervision and privacy review.

Course badges require an approved course and a verified ParaLearn test pass. The DAI school certificate requires all eight courses and a verified mixed school exam, human marking and independent moderation of written responses, and authorised signatures from the Head of Learning and Founder Prof. Mina Ogbanga.

The ZIP contains the 28 learner files and this README. The public source repository contains review examples. Use unpublished items for graded ParaLearn exams.
