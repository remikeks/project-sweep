## Learning boundaries and media

Guides and every worksheet page state: use the supplied fictional adult scenarios; do not collect real disclosures or submit survivor records. Learners may pause or use an alternative fictional exercise. No forced disclosure or distressing performance is assessed. First response avoids incident records and investigation; specialist casework needs appropriate qualified systems. Individual clinical, forensic, legal, child/adolescent and safeguarding decisions remain with the relevant roles and current local procedures. No real referral directory, crisis number, diagnosis or medical cut-off is invented.

The four-file `pdf_slides` standard supplies a guide PDF, worksheet PDF, editable PPTX and matching slide PDF per course. Guides use 12-point body text, correct GBV identity and course/version furniture. Slides preserve the established SWEEP background and navy/green/white style. Full teaching and source appraisal accompany concise editable teaching points. Videos and captions/checked transcripts are later work; no video is claimed.

The compiler now accepts source-specific evidence dates and extra review requirements while preserving old defaults and deterministic exports. The PDF builder accepts optional study/practice guidance; prior batches are not rebuilt. Actual-file verification checks the required study text and every worksheet boundary as well as all source teaching and teaching points. The live slide-authoring service returned an execution-environment availability error, so the established Artifact Tool file workflow is used, with actual PPTX-to-PDF rendering through isolated LibreOffice and Poppler visual QA.
