# PCEI private learner-resource review bundle

Twenty resources: five learner-guide PDFs, five three-page practice worksheet PDFs, five editable PPTX decks and five PDFs rendered from those actual final PPTX files. Courses SWP-061–065 remain inactive; resources private/in review, not approved learner releases. No videos are included or claimed.

Design follows the existing SWEEP navy/green/white layout and existing community-learning background. Guides and worksheets embed Liberation Sans regular/bold with 12-point body text. Deck counts are 15/16/15/16/16 (78 total), each 13 + ceiling(unique used sources / 2). Guides are 7/7/6/7/8 pages; worksheets 3 each. Total final PDF pages: 128. Source appraisals and context/rights limitations are in each guide and internal source README.

Only original fictional scenarios and invented aggregates are used. Do not submit real complainant/child/survivor records, personal histories or recruit people for fieldwork. Alternative fictional exercise allowed. Practicum is introductory simulated/supervised learning, not completed field placement or independent professional competence. Grievance facilitation is not investigation/adjudication or a replacement for qualified safeguarding/emergency routes.

`scripts/build_pcei_source.py` rebuilds source/exam JSON. `scripts/build_pcei_media.py` reuses the established PDF and Artifact Tool scripts, takes explicit font/runtime/renderer paths and renders the actual PPTX through isolated LibreOffice before Poppler. `upload_manifest.json` contains actual sizes and SHA256 values; `package_validation.json` checks accessible text and teaching points in actual files. `visual_qa.json` identifies the exact reviewed hashes/pages. Rebuilding may change binary hashes; revalidate and visually inspect every regenerated page before staging. Never retain an old QA declaration for new bytes.

The 21-entry learner ZIP contains these twenty media files plus this README only. No MCQ answer key, staff model answer, rubric, raw paper, private receipt, credential, operational record or secret belongs in it. Source/exam JSON stays in a separate staff transport. An approved course plus a verified ParaLearn course-CBT pass is required for a badge; school certification additionally needs every approved school course, final mixed exam, human written marking, independent moderation and authorised signatures. Academic/local-practice/safeguarding/accessibility/pilot/supervised-skills reviews and ParaLearn provider verification remain pending.
